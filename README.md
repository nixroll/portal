# Портал — платформа

Весь код продукта «Портал»: кабинет ресторана, будущие приложения и виджеты.

## Структура

```
platform/
  apps/
    dashboard/        кабинет заведения (сейчас: настройки бронирования)
      index.html      одна страница, чистые HTML/CSS/JS, шрифт Inter
  experiments/
    libraries-dev/    эксперимент со скином на Libraries.dev (не в работе)
```

## Как открыть

Открыть `apps/dashboard/index.html` в браузере. Сборка не нужна.
Настройки сохраняются в `localStorage` браузера, бэкенда пока нет.

## Правила

- Шрифт везде Inter.
- Межстрочный интервал в целых пикселях, текст со сглаживанием `antialiased` — для чёткого рендера.
- Дизайн-макеты: Figma, файл Portal, страница «Портал».
