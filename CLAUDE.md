# Портал — правила работы с кодом

## Где что лежит
- Репозиторий: `nixroll/portal` (публичный), ветка `main`.
- Копия на компьютере Никиты: `~/Claude/Портал/platform/` — это корень репозитория.
  Рядом с `platform/` лежат документы проекта (юридическое, аналитика), они в репозиторий не входят.
- Кабинет: `apps/dashboard-v3/` — актуальная версия (главная ссылка и /v3/).
  `apps/dashboard-v2/` и `apps/dashboard-v1/` (v1) — архив: в репозитории есть, на сайт не публикуются (`_config.yml` → exclude).
  Эксперименты — в `experiments/`.

## Как вносить изменения
1. Перед работой синхронизировать: последняя версия — в GitHub; папку на компьютере обновить из репозитория.
2. Повседневная работа — в песочнице Claude: правки показываем в артефакте, в GitHub не пушим.
3. Деплой — только по команде Никиты («задеплой на GitHub»):
   файлы записать в `~/Claude/Портал/platform/` → коммит → пуш в `main`.
   Публичная ссылка: https://nixroll.github.io/portal/ (GitHub Pages, обновляется ~1 мин после пуша).
4. Откат — только `git revert` (новый коммит поверх), без `reset` и принудительного пуша.
5. Коммиты на русском, коротко: что изменилось и зачем.
6. Не коммитить секреты (ключи MCP, токены, `.env`).
7. Figma держать в соответствии с кодом — обновлять макеты по просьбе Никиты.

## Дизайн и код
- Чистые HTML/CSS/JS, без сборки, пока не решено иное.
- Шрифт везде Inter.
- Чёткий рендер: `-webkit-font-smoothing: antialiased`, межстрочный интервал в целых пикселях
  (`line-height: round(1.45em, 1px)`), без `translate(-50%)` для текста — позиции в целых пикселях.
- Без иконок и декора, кроме тех, что есть в макете Figma (Sidebar / Nav item).
- Макеты v3: Figma, файл Portal, секции «Portal Light» и «Portal Dark», дизайн-системы «Sidebar» и «Toolbar».
- Рамки 0,5 px рисуем тенью внутрь (box-shadow), позиции округляем до физических пикселей (на ретине допустимы половинки).
