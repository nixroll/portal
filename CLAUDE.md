# Портал — правила работы с кодом

## Где что лежит
- Репозиторий: `nixroll/portal` (приватный), ветка `main`.
- Копия на компьютере Никиты: `~/Claude/Портал/platform/` — это корень репозитория.
  Рядом с `platform/` лежат документы проекта (юридическое, аналитика), они в репозиторий не входят.
- Каждый продукт — отдельная папка в `apps/` (сейчас `apps/dashboard/`). Эксперименты — в `experiments/`.

## Как вносить изменения
1. Перед работой синхронизировать: последняя версия — в GitHub; папку на компьютере обновить из репозитория.
2. Правка → проверка в браузере → коммит → пуш в `main` → те же файлы записать в `~/Claude/Портал/platform/`.
3. Коммиты на русском, коротко: что изменилось и зачем.
4. Не коммитить секреты (ключи MCP, токены, `.env`).

## Дизайн и код
- Чистые HTML/CSS/JS, без сборки, пока не решено иное.
- Шрифт везде Inter.
- Чёткий рендер: `-webkit-font-smoothing: antialiased`, межстрочный интервал в целых пикселях
  (`line-height: round(1.45em, 1px)`), без `translate(-50%)` для текста — позиции в целых пикселях.
- Без иконок и декора, кроме тех, что есть в макете Figma (Sidebar / Nav item).
- Макеты: Figma, файл Portal, страница «Портал» (фрейм «Бронирование — Desktop 1440»).
